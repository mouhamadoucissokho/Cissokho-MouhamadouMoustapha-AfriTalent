 # AfriTalent

Plateforme de mise en relation entre freelances tech africains et entreprises du monde entier.

## Auteur
- **Nom :** Mouhamadou Moustapha Cissokho
- **Classe :** L1 CS — ISI

## Description
AfriTalent est un site vitrine complet permettant aux freelances africains de présenter leurs services et aux entreprises de trouver les talents dont elles ont besoin.

## Technologies utilisées
- HTML5 sémantique
- CSS3 (Flexbox, Grid, Bento Grid, animations)
- Bootstrap 5
- JavaScript vanilla
- Bootstrap Icons
- Google Fonts (Orbitron, DM Sans, Space Mono)

## Fonctionnalités principales
- Dark mode / Light mode (localStorage)
- Compteurs animés au scroll
- Filtrage dynamique des freelances
- Validation formulaire de contact
- Navbar dynamique au scroll
- Animations fade-in au scroll
- Bouton retour en haut
